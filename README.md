# FeedbackIQ – CP-039

Course Feedback Sentiment and Ratings Analyser.

## Features
- Add student feedback
- Five rating parameters from 1 to 5
- Course average analysis
- Faculty average analysis
- Keyword-based positive/negative/neutral sentiment
- Flag courses when any parameter average is below 3
- Faculty reports with strengths and areas to improve
- Browser local storage for saved feedback

## Files
- `index.html` – website structure
- `style.css` – styling
- `script.js` – application logic

## Run locally
Open `index.html` in a web browser.

## GitHub Pages
Upload all three files to a GitHub repository and enable:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
